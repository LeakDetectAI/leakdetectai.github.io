03 / CONTEXT

Keep rankings separate

ICORE conference rankings ↗SCImago journal quartiles ↗DBLP venue history ↗

Journal quartiles: Q1 = top 25%; Q2 = 25–50%; Q3 = 50–75%; Q4 = bottom 25% within a subject category and year. Quartiles can differ by category. SJR is a citation-based indicator that weights citations by the influence of the citing journals. CORE grades and SCImago quartiles are not equivalent.

This is a manually maintained source snapshot with live browser countdowns. Conflicting observations are shown in each record; an official observation wins. Conference badges use ICORE2026. Journal badges use SCImago and explicitly state the metric year and quartile scope. Historical snapshots, secondary sources and owner-supplied SCImago values are labeled separately; none is presented as direct latest-edition verification. Rank verification is separate from deadline verification. ARR submission and conference commitment are separate milestones. Regex-friendly official URL patterns and source links are stored in source-links.json.

Deadline time note: All submission deadlines are set to 11:59 PM AoE (Anywhere on Earth), which corresponds to the UTC−12 time zone, unless an official source explicitly gives a different time zone.
